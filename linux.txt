1. 파일 찾기
   - find [경로] [옵션] [파일명]
   - ex> find / -name '*.apk'

2. timezone 설정
   - timedatectl  : 현재 설정 확인
   - sudo timedatectl set-timezone Asia/Seoul  : 설정 변경

3. 팁
   - '~'는 Home Directory를 뜻한다.
   - library.a 는 라이브러리의 정적 버전
   - library.so.version 은 공유 라이브러리

4. 많이 사용하는 명령어
   - ls -l : 자세한 목록
   - chmod 755 fileName : 소유자는 rwx, 그룹및기타는 r-x로 설정
   - chown user file : 파일 소유자 변경
   - pwd, sudo, cat, head, tail
   - ps -ef : 전체 프로세스 표시
   - kill [PID] : 프로세스 종료
